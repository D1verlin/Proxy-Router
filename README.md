# Smart Proxy Router (Chrome Extension)

Браузерное расширение для Google Chrome (Manifest V3), предназначенное для выборочной маршрутизации сетевого трафика заданных веб-сервисов через указанный HTTP-прокси.

---

## Маршрутизация трафика

Расширение разделяет сетевые запросы браузера на три категории:

### 1. Трафик через прокси-сервер
Запросы к следующим сервисам направляются через настроенный прокси:
* **Google Services:** `google.com`, `google.ru`, региональные домены поиска, сопутствующие сервисные ресурсы (`gstatic.com`, `googleapis.com`, `googleusercontent.com`, `googletagmanager.com` и др.).
* **Google Gemini & AI Studio:** `gemini.google.com`, `aistudio.google.com`, `generativelanguage.googleapis.com`, `deepmind.google`.
* **Anthropic Claude:** `claude.ai`, `anthropic.com`, `claude.site`.
* **OpenAI / ChatGPT:** `chatgpt.com`, `openai.com`, `oaistatic.com`, `oaiusercontent.com`, `sora.com`.
* **Google Stitch:** `stitch.withgoogle.com`, `withgoogle.com`, `stitch.google.com`.
* **Пользовательские домены:** дополнительные хосты, добавленные через интерфейс управления.

### 2. Прямой трафик (Direct / Bypass)
* **YouTube:** `youtube.com`, `m.youtube.com`, `youtu.be`, `googlevideo.com`, `ytimg.com` и связанные CDN-сервисы всегда исключаются из проксирования и подключаются напрямую.

### 3. Остальной веб-трафик
Все веб-ресурсы, не входящие в список целевых сервисов, обрабатываются в штатном режиме через прямое сетевое подключение пользователя.

---

## Установка

1. Открыть браузер Google Chrome и перейти по адресу:
   ```
   chrome://extensions/
   ```
2. В правом верхнем углу окна активировать параметр **«Режим разработчика»** (*Developer mode*).
3. Нажать кнопку **«Загрузить распакованное расширение»** (*Load unpacked*).
4. Указать путь к корневой директории проекта.
5. Закрепить ярлык расширения на панели инструментов браузера для быстрого доступа.

---

## Конфигурация и управление

Через всплывающее окно расширения доступны следующие параметры:

* **Главный переключатель (Master Switch):** глобальное включение и отключение маршрутизации. При отключении сетевой стек браузера возвращается в режим по умолчанию (`system`).
* **Селекторы сервисов:** независимое включение или выключение проксирования для отдельных платформ (Google, Gemini, Claude, OpenAI, Stitch).
* **Сетевые параметры прокси:** возможность изменения хоста (IP/домена) и порта прокси-сервера.
* **Пользовательские списки доменов:**
  * Добавление собственных доменов в список проксирования.
  * Добавление доменов в список исключений для прямого доступа.
* **Резервное прямое соединение (Fallback):** опция переключения на `DIRECT` при сбое или недоступности прокси.
* **Сброс настроек:** восстановление исходных параметров конфигурации.

---

## Архитектура и реализация

* **Спецификация:** Manifest V3 (`service_worker`).
* **Механизм маршрутизации:** динамическая генерация и применение PAC-скрипта (Proxy Auto-Config) через `chrome.proxy.settings`.
* **Изоляция:** вычисление правил маршрутизации производится нативно внутри сетевого стека Chromium V8.
* **Хранилище конфигурации:** локальное хранилище браузера (`chrome.storage.local`). Внешние аналитические сервисы и передача пользовательских данных отсутствуют.
